# Exercice 1 — Corrigé

- Versions : dépendent de ta machine (ex. `v22.x`, `10.x`, `git version 2.4x`).
- `[3, 8, 1].map(n => n * 10)` → `[ 30, 80, 10 ]`
- Après `"backend".toUpperCase()`, `_` vaut `'BACKEND'` (le dernier résultat évalué).
- `npm run dev` : à chaque sauvegarde, Node affiche `Restarting 'server.js'` et relance le programme.
- `npm i -D nodemon` l'ajoute dans **`devDependencies`** (et crée `node_modules/` + `package-lock.json`).
